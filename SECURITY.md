# Security

Please report security issues privately to **ask@fluos.io** with "Security" in the subject. Don't open a public issue or post details elsewhere.

Include the Fluos Connect version (menu bar → the version line), your macOS version and the steps to reproduce. We'll reply within 3 working days.

Only the latest release gets security fixes. The app updates itself, and Fluos can require an update for versions with a known issue.
